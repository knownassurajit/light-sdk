# 🛠️ Light SDK Gradle Plugin (`light-sdk/plugin`)

The `plugin` module provides the custom Gradle plugin for automating Light OS app packaging, manifest generation, and resource linting during Gradle build cycles.

---

## 🏗️ Structure

```text
plugin/
├── src/main/java/com/light/sdk/plugin/
│   └── LightPlugin.kt    # Gradle plugin entry point & task definitions
└── build.gradle.kts      # Gradle plugin publishing rules
```
