# 🔍 Light SDK Custom Lint Rules (`light-sdk/lint-rules`)

The `lint-rules` module contains custom Android Lint rules and AST detectors enforcing Light OS UI constraints, memory boundaries, and e-ink display guidelines.

---

## 🛠️ Detectors

- **EInkContrastDetector**: Enforces high-contrast monochrome design compliance.
- **BackgroundProcessingDetector**: Flags unauthorized long-running background tasks.
